# Translation results

Results of translating benchmark queries with the generators and running them on each system.

| Folder | Content |
|---|---|
| `benchmark_tests/` | benchmark queries as YAML (`tst_NN.yaml`), the generated PostGIS, Sedona and SpaceTime versions (`tst_NN_<system>.txt`), their outputs, and `expected.txt` |
| `benchmark_cycling_tests/` | the same for the cycling scenario, with `tests_summary.txt` (which translations ran and matched) and `pdf_tests/` |
